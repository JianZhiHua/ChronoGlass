# ChronoGlass

**ChronoGlass** 是一个基于 `Python + PyQt6` 的 Windows 桌面计时器，提供系统时钟、倒计时、秒表和闹钟四种模式，强调低干扰、常驻桌面、快速操作和本地持久化。

整体界面采用 Nord 风格深色主题，主窗口无边框、支持透明背景、任意位置拖动和托盘常驻，适合放在桌面侧边长期使用。

## 功能概览

- 四种模式一体化：系统时钟、倒计时、秒表、闹钟管理
- 无边框悬浮窗口：始终置顶、半透明、任意位置拖动
- 托盘集成：左键单击托盘图标可显示/隐藏窗口，右键呼出完整菜单
- 本地持久化：闹钟、天气位置等状态统一保存到 `chronoglass_state.json`
- 纯代码 UI 控件：自绘开关、自定义步进器，减少打包后资源缺失问题

## 当前特性

### 1. 系统时钟模式

- 显示当前时间，精确到秒
- 显示日期、星期和天气信息
- 支持双击时钟界面设置天气位置，例如 `北京`、`Shanghai`
- 天气使用 `wttr.in` 获取，后台线程异步请求，避免阻塞 UI
- 每 30 分钟自动刷新天气
- 显示下个节日和最近节气，并附带剩余天数
- 当天正好是节气时，直接显示 `今天`
- 节日名过长时自动截断，避免第二行文本挤压布局
- 显示农历日期与简化黄历宜忌信息
- 若未安装 `lunar_python`，程序仍可运行，只是不显示农历/节气/节日信息

### 2. 倒计时模式

- 默认倒计时时长为 20 分钟
- 支持空格键启动/暂停
- 支持鼠标滚轮以分钟为单位快速增减时长
- 支持双击界面直接输入倒计时分钟数
- 时间到后自动停止并触发系统提示音
- 不同状态对应不同高亮颜色：运行中、暂停、结束

### 3. 秒表模式

- 支持空格键启动/暂停
- 实时显示累计计时时长
- 可通过托盘菜单重置当前计时

### 4. 闹钟模式

- 支持添加、修改、删除闹钟
- 支持两种重复规则：`一次性`、`每天`
- 闹钟列表显示时间、标签、重复类型、剩余时间和启用状态
- 剩余时间显示更精确，支持小时/分钟/秒组合展示
- 一次性闹钟触发后自动标记为已触发并禁用
- 每日闹钟触发后不会在同一天内重复弹窗
- 为避免 `QTimer` 抖动导致漏响，闹钟采用时间窗口判定，不再依赖严格相等秒数
- 闹钟触发时弹出置顶提醒框，并提供以下操作：
  - `延时5分钟`
  - `修改设置`
  - `完成`
- 触发时会播放系统提示音

## 交互说明

| 操作 | 说明 |
| :--- | :--- |
| 左键单击托盘图标 | 显示或隐藏主窗口 |
| 右键点击窗口或托盘 | 打开托盘菜单 |
| 点击右上角 `⇆` | 依次切换模式 |
| 点击右上角 `—` | 隐藏到托盘 |
| 点击右上角 `×` | 退出程序 |
| 空格键 | 在倒计时或秒表模式下启动/暂停 |
| 鼠标滚轮 | 在倒计时模式下按分钟增减时长 |
| 双击窗口 | 倒计时模式下设置分钟数；系统时钟模式下设置天气位置 |
| 鼠标左键拖动窗口 | 移动无边框主窗口 |

## 托盘菜单

托盘菜单提供以下功能：

- 切换到系统时钟模式
- 切换到倒计时模式
- 切换到秒表模式
- 切换到闹钟模式
- 重置当前计时
- 打开闹钟设置
- 彻底退出程序

## 数据存储

程序运行时会在当前目录生成统一状态文件：

- `chronoglass_state.json`

其中包含：

- 天气位置等配置
- 闹钟列表
- 闹钟重复规则
- 闹钟最近触发日期

示例结构：

```json
{
  "version": 1,
  "config": {
    "location": "北京"
  },
  "alarms": [
    {
      "time": "20:55:00",
      "name": "晚间提醒",
      "enabled": true,
      "repeat": "daily",
      "last_trigger_date": ""
    }
  ]
}
```

### 旧数据迁移

如果目录中仍存在旧版的：

- `alarms.json`
- `config.json`

新版本会在首次启动时自动读取并迁移到 `chronoglass_state.json`。旧文件不会被自动删除。

### 日志文件

程序发生读写异常、天气请求异常或提示音调用异常时，会追加写入：

- `chronoglass.log`

## 运行环境

- Windows 10 / 11
- Python 3.x

## 依赖

必需依赖：

- `PyQt6`

可选依赖：

- `lunar_python`

打包相关依赖：

- `nuitka`
- `zstandard`

## 开发运行

安装依赖后，直接运行：

```bash
python ChronoGlass.py
```

如果需要启用农历、节气和节日信息，请额外安装：

```bash
pip install lunar-python
```

## 打包说明

项目提供了 Windows 批处理脚本 `build.bat`，用于自动完成打包与签名。

脚本会执行以下流程：

1. 检查 `.venv`、图标、证书和 VS2019 工具链是否存在
2. 清理旧的 `out` 目录
3. 使用 Nuitka 构建单文件 `.exe`
4. 调用 `signtool` 进行数字签名
5. 对 `VsDevCmd` 和 `signtool` 的失败情况做显式检查，失败时立即退出，不会误报“构建成功”

### 构建前提

- 已创建 `.venv`
- `.venv\Scripts\python.exe` 可用
- 根目录存在 `tray_icon.ico`
- 根目录存在 `mycert.pfx`
- 已安装 Visual Studio 2019，并且 `VsDevCmd.bat` 路径与脚本配置一致

直接运行：

```bat
build.bat
```

## 项目结构

- `ChronoGlass.py`：主程序源码
- `build.bat`：构建与签名脚本
- `tray_icon.ico` / `tray_icon.png`：程序图标资源
- `mycert.pfx`：签名证书
- `chronoglass_state.json`：运行时生成的统一状态文件
- `chronoglass.log`：运行时异常日志
- `out/`：构建输出目录

## 已实现的稳定性改进

- 天气请求使用后台线程，避免界面卡死
- 天气请求增加并发保护，避免重复发起多个网络请求
- 状态文件使用原子写入，降低异常中断导致数据损坏的风险
- 闹钟增加去重逻辑，避免同一天内重复弹窗
- 打包脚本对签名失败增加显式错误处理
