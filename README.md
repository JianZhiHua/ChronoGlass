
# ChronoGlass - 极简几何计时器

**ChronoGlass** 是一款专为高效工作设计的桌面计时工具。采用 Nord 暗色系视觉风格，支持无边框半透明窗口与动态颜色反馈，旨在提供最直观、无干扰的时间管理体验。

## ✨ 核心特性

* **三模切换**：集成了系统时钟、倒计时、正计时（秒表）三大功能。
* **全中文状态显示**：左上角实时显示“系统时钟”、“正在倒计时”等状态信息。
* **动态颜色反馈**：
    * 🕒 **系统时钟**：冰蓝色 (Nord Blue)。
    * ⏳ **倒计时**：进行中为黄色，暂停为绿色，时间到自动转为警示红。
    * ⏱️ **秒表计时**：运行状态为紫色，提供清晰的任务耗时统计。
* **极简 UI 设计**：
    * **图标化控制**：右上角仅保留模式切换 (⇆) 与彻底退出 (×) 图标按钮。
    * **无边框拖拽**：支持鼠标左键点击窗口任意位置进行平滑拖动。
    * **统一外边框**：所有界面元素均包裹在统一的 Nord 风格圆角边框内。
* **托盘集成**：支持系统托盘运行，右键托盘图标可进行模式直达、重置或退出。

## ⌨️ 交互指南

| 动作 | 功能说明 |
| :--- | :--- |
| **空格键 (Space)** | 启动 / 暂停当前计时（在倒计时或秒表模式下） |
| **鼠标滚轮** | 在倒计时模式下，滚动滚轮可快速增减分钟数 |
| **左键双击时间** | 在倒计时模式下，弹出输入框设定精确的计时分钟数 |
| **右键点击窗口** | 弹出功能菜单，支持模式直跳、设定时间与重置功能 |

## 🛠️ 构建与开发

项目内置了完整的自动化环境检测与打包脚本。

### 环境要求
* Python 3.x
* 依赖库：`PyQt6`, `nuitka`, `zstandard`
* 构建环境：Windows 10/11 + Visual Studio 2019 (用于数字签名)

### 自动化打包流程
直接运行项目根目录下的 `build.bat`，脚本将自动完成以下操作：
1.  **环境体检**：自动验证虚拟环境 (`.venv`)、数字证书 (`mycert.pfx`) 及图标资源是否就位。
2.  **清理旧档**：自动强制删除旧的 `out` 构建目录。
3.  **高性能编译**：使用 Nuitka 将代码编译为具备文件描述信息的单文件 `.exe`。
4.  **数字签名**：调用 `signtool` 自动为程序加盖 **HuanQingYi** 开发者证书，减少杀毒软件误报。

## 📁 项目结构

* `ChronoGlass.py`: 应用程序核心逻辑代码。
* `build.bat`: 自动化环境检测、打包与签名脚本。
* `mycert.pfx`: 开发者数字证书（用于程序签名）。
* `tray_icon.ico` / `.png`: 程序图标资源。
