# ChronoGlass - 极简几何计时器

**ChronoGlass** 是一款专为高效工作设计的桌面时间管理工具。采用 Nord 暗夜系视觉风格，支持无边框半透明窗口与动态颜色反馈，旨在提供最直观、无干扰的沉浸式体验。

## ✨ 核心特性

* **四模无缝切换**：集成了系统时钟、倒计时、正计时（秒表）以及**任务闹钟**四大核心功能。
* **全中文状态显示**：左上角实时显示当前模式及状态信息。
* **动态颜色与交互反馈**：
    * 🕒 **系统时钟**：冰蓝色 (Nord Blue)。
    * ⏳ **倒计时**：进行中为黄色，暂停为绿色，时间到自动转为警示红。
    * ⏱️ **秒表计时**：运行状态为紫色，提供清晰的任务耗时统计。
    * ⏰ **闹钟与任务**：橙色管理界面。时间触发时，弹出原生级别的置顶高亮模态提醒框，并伴随系统提示音，支持“延时 5 分钟”、“修改”与“完成”。
* **极简 UI 与动画设计**：
    * **纯代码渲染**：使用内联纯代码绘制平滑 Toggle 胶囊开关与 `+ / -` 步进器，免疫任何打包丢图问题。
    * **图标化控制**：右上角仅保留模式切换 (`⇆`)、最小化到托盘 (`—`) 与彻底退出 (`×`) 按钮。
    * **无边框拖拽**：支持鼠标左键点击窗口任意位置进行平滑拖动。
* **后台与持久化**：
    * **本地数据储存**：任务列表与状态自动持久化保存至当前目录的 `alarms.json`，下次打开无缝恢复。
    * **托盘级集成**：支持最小化至系统托盘静默运行，左键单击托盘图标即可快速唤醒/隐藏主窗口。

## ⌨️ 交互指南

| 动作 | 功能说明 |
| :--- | :--- |
| **鼠标左键单击托盘** | 快速唤醒（前置显示）或隐藏主窗口 |
| **右键点击窗口/托盘** | 呼出完整菜单，支持模式直跳、闹钟设置、重置与退出 |
| **空格键 (Space)** | 启动 / 暂停当前计时（在倒计时或秒表模式下） |
| **鼠标滚轮** | 在倒计时模式下，滚动滚轮可快速增减分钟数 |
| **左键双击时间** | 在倒计时模式下，弹出输入框设定精确的计时分钟数 |
| **点击右上角 `—`** | 窗口消失，静默最小化至系统托盘 |

## 🛠️ 构建与开发

项目内置了完整的自动化环境检测与打包脚本。

### 环境要求
* Python 3.x
* 依赖库：`PyQt6`, `nuitka`, `zstandard`
* 构建环境：Windows 10/11 + Visual Studio 2019 (用于数字签名)

### 自动化打包流程
直接运行项目根目录下的 `build.bat`，脚本将自动完成以下操作：
1.  **环境体检**：自动验证虚拟环境 (`.venv`)、数字证书 (`mycert.pfx`) 及图标资源是否就位。
2.  **清理旧档**：自动强制删除旧的 `out` 构建目录。
3.  **高性能编译**：使用 Nuitka 将代码编译为具备文件描述信息的单文件 `.exe`。
4.  **数字签名**：调用 `signtool` 自动为程序加盖 **HuanQingYi** 开发者证书，减少杀毒软件误报。

## 📁 项目结构

* `ChronoGlass.py`: 应用程序核心逻辑代码。
* `build.bat`: 自动化环境检测、打包与签名脚本。
* `mycert.pfx`: 开发者数字证书（用于程序签名）。
* `tray_icon.ico` / `.png`: 程序系统托盘与窗口图标。
* `alarms.json`: *[运行时自动生成]* 用户设定的闹钟与任务持久化数据。
